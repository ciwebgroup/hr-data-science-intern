# Icon Usage Guidelines

## Design Principles
- **Consistency**: All icons should follow the same visual weight and style
- **Scalability**: Icons must work at both small (16px) and large (128px) sizes
- **Brand Alignment**: Colors should complement CI Web Group's brand palette
- **Professional Appeal**: Clean, modern aesthetic that appeals to technical talent

## Application Contexts

### **Booth Materials**
- **Technology Stack Poster**: Large format display showing all tools
- **Interactive Displays**: Clickable icons linking to demo videos
- **Handout Materials**: Small icons next to technology descriptions

### **Digital Assets**
- **Website Integration**: Career page and internship descriptions
- **Social Media**: Technology highlight posts and stories
- **Presentation Slides**: Visual enhancement for job fair presentations

### **Branded Items**
- **Stickers**: Individual technology icons for laptop decoration
- **Postcards**: Technology stack overview cards
- **Digital Wallpapers**: Desktop backgrounds featuring icon collections

## Color Palette Integration

### **Primary Brand Colors**
- **CI Web Group Blue**: #1E40AF
- **Accent Orange**: #F97316
- **Professional Gray**: #6B7280
- **Success Green**: #10B981

### **Technology Color Harmony**
- Icons should maintain their authentic brand colors while ensuring harmony
- Use CI Web Group colors for backgrounds, borders, and accent elements
- Ensure sufficient contrast for accessibility (4.5:1 minimum)

---

# Implementation Recommendations

## Sourcing Strategy
1. **Official Brand Assets**: Use authentic logos where available
2. **Professional Icon Libraries**: Feather Icons, Heroicons, or custom designs
3. **Consistent Style**: Maintain uniform line weight and corner radius
4. **High Resolution**: Vector formats (SVG) preferred for scalability

## Quality Standards
- **Resolution**: Minimum 300 DPI for print materials
- **Format**: SVG for digital, PNG with transparency for complex applications
- **Licensing**: Ensure proper licensing for commercial use
- **Accessibility**: Include alt-text descriptions for all icons
