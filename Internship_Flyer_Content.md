# Production Specifications

## Print Requirements
- **Paper Stock**: 14pt C2S (Coated Two Sides) cardstock
- **Coating**: Matte finish for reduced glare
- **Color Profile**: CMYK with Pantone color matching
- **Bleed**: 0.125" on all sides
- **Safe Zone**: 0.25" margin from trim edge

## Quality Control
- **Proof Review**: Digital proof approval before printing
- **Color Accuracy**: Pantone color matching for brand consistency
- **Text Legibility**: Minimum 8pt font size for all text
- **Image Resolution**: All images minimum 300 DPI at print size

## Distribution Strategy
- **Primary Distribution**: Job fair booth take-away
- **Secondary Uses**: Campus visits, networking events, mail campaigns
- **Digital Version**: PDF available for email distribution
- **Quantity Planning**: 400 initial print run with reorder capability
